# Cybersecurity Foundations Portfolio

A portfolio of ten artifacts demonstrating cybersecurity foundations across networks, Linux, attacks, defences, investigation and risk-based decision-making, produced over a ninety-day course.

**Author:** Varun Chowdary Challagundla
**📄 Read the full portfolio:** [`Cybersecurity_Foundations_Portfolio.pdf`](Cybersecurity_Foundations_Portfolio.pdf)

## The journey

The work moves from securing one person's accounts to making prioritisation decisions for an organisation, from following a method to exercising judgement. The same habits recur throughout: evidence before conclusions, honest confidence levels, and recommendations someone could act on the same day.
